Type ordinary words for a general search. Start with = to use a structured query in Fulltext.

Fields: cd, title, artist, composer, year, label, catno, notes, cdcount, bay, shelf. For shelf, use the physical code shown by the location dialog, such as L03, C04, or A02.

Use has: or missing: with ripped, frontcover, backcover, composer, musicbrainz, listenbrainz, discogs, qobuz, or naxos.

Use AND / OR (or & / |) between conditions. Quote a value containing spaces. Parentheses are not supported.
